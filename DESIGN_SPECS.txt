==========================================================================
ESPECIFICACIONES DE DISEÑO - SISTEMA DE GESTIÓN DE TIENDAS
==========================================================================

INFORMACIÓN GENERAL:
- Proyecto: Sistema de Gestión de Tiendas con Autenticación JWT
- Framework: Flask + Bootstrap 4.5.2 + jQuery + Font Awesome
- Base de datos: SQLite con 12,545+ tiendas
- Autenticación: JWT con roles (ADMIN/USER)
- Idioma: Español

==========================================================================
ESTRUCTURA DE LA APLICACIÓN
==========================================================================

PÁGINA PRINCIPAL: http://localhost:5000/

NAVEGACIÓN SUPERIOR:
- Logo: "Sistema de Tiendas" con icono de tienda
- Color: Navbar azul Bootstrap (bg-primary)
- Para usuarios NO autenticados:
  * Botón "Iniciar Sesión" (outline-light)
  * Botón "Registrarse" (light)
- Para usuarios autenticados:
  * Saludo con nombre de usuario
  * Badge con rol (ADMIN/USER)
  * Dropdown con opciones:
    - Mi Perfil
    - [SOLO ADMIN] Gestión de Usuarios
    - [SOLO ADMIN] Estadísticas
    - Cerrar Sesión

PANELES DE LA APLICACIÓN
==========================================================================

1. PANEL DE AUTENTICACIÓN (Visitantes)
   ====================================
   FORMULARIO DE LOGIN:
   - Campos: Usuario/Email, Contraseña
   - Botón: "Iniciar Sesión" (azul)
   - Enlace: "¿No tienes cuenta? Regístrate aquí"
   
   FORMULARIO DE REGISTRO:
   - Campos: Username, Email, Contraseña, Confirmar Contraseña
   - Validaciones:
     * Username: 3-20 caracteres, letras, números, guiones
     * Email: formato válido
     * Contraseña: 8+ chars, mayús, minús, número, símbolo
   - Botón: "Registrarse" (verde)
   - Enlace: "¿Ya tienes cuenta? Inicia sesión aquí"

2. PANEL PRINCIPAL DE TIENDAS (Usuarios autenticados)
   =================================================
   ENCABEZADO:
   - Título: "Gestión de Tiendas" con icono
   - [SOLO ADMIN] Botón "Nueva Tienda" (verde, esquina derecha)
   - [SOLO ADMIN] Texto: "Solo administradores pueden gestionar tiendas"
   
   CONTROLES:
   - Botón "Actualizar" con icono de sincronización
   - Selector de "Por página": 10, 25, 50, 100 elementos
   - Información de paginación: "Página X de Y"
   
   NAVEGACIÓN:
   - Botones: Primera, Anterior, [Página actual], Siguiente, Última
   - Estados activo/inactivo según la página actual
   
   TARJETAS DE TIENDAS:
   - Diseño: Grid de 3 columnas (col-lg-4)
   - Cada tarjeta contiene:
     * Header: "Tienda #ID" + [SOLO ADMIN] botones Editar/Eliminar
     * Información organizada en 2 columnas:
       - Columna 1: Área (m²), Clientes diarios
       - Columna 2: Artículos disponibles, Ventas ($)
     * Iconos Font Awesome para cada métrica
     * Efectos hover: elevación y sombra
   
   BOTONES DE ADMINISTRADOR (en cada tienda):
   - Botón Editar: azul, icono lápiz, tooltip "Editar tienda"
   - Botón Eliminar: rojo, icono basura, tooltip "Eliminar tienda"
   - Agrupados con btn-group para mejor presentación

3. FORMULARIO DE TIENDA (Solo administradores)
   ===========================================
   - Ubicación: Debajo de la lista de tiendas
   - Estados: "Nueva Tienda" o "Editar Tienda #ID"
   - Campos organizados en 2 columnas:
     * Columna 1: Área (m²), Clientes diarios
     * Columna 2: Artículos disponibles, Ventas ($)
   - Validaciones: números requeridos, decimales permitidos
   - Botones: "Guardar" (verde), "Cancelar" (gris)

4. PANEL DE GESTIÓN DE USUARIOS (Solo administradores)
   ==================================================
   - OCULTO POR DEFECTO - Solo se muestra al seleccionar del menú
   - Botón "Nuevo Usuario" en header
   - Lista de usuarios en tabla:
     * Columnas: Username, Email, Rol, Estado, Último login, Acciones
     * Badge de colores para roles y estados
     * Botones por usuario: Editar, Cambiar rol, Activar/Desactivar
   
   FORMULARIO DE USUARIO:
   - Campos: Username, Email, Contraseña, Rol
   - Dropdown para rol: Usuario Regular, Administrador
   - Validaciones similares al registro

5. PANEL DE ESTADÍSTICAS (Solo administradores)
   ============================================
   - OCULTO POR DEFECTO - Solo se muestra al seleccionar del menú
   - Diseño de cards con gradiente azul
   - Estadísticas del sistema:
     * Total de tiendas
     * Total de usuarios
     * Usuarios activos/inactivos
     * Administradores registrados

==========================================================================
FLUJO DE USUARIO
==========================================================================

USUARIO NO AUTENTICADO:
1. Ve página de login/registro
2. Puede registrarse como usuario normal
3. Después del login → Panel de tiendas (solo lectura)

USUARIO NORMAL:
1. Login → Panel de tiendas automáticamente
2. Puede navegar y ver todas las tiendas
3. NO ve botones de edición/eliminación
4. NO puede acceder a gestión de usuarios ni estadísticas

ADMINISTRADOR:
1. Login → Panel de tiendas automáticamente
2. Ve botones de edición/eliminación en cada tienda
3. Puede crear nuevas tiendas
4. Acceso a menú desplegable con:
   - Gestión de Usuarios (click para mostrar panel)
   - Estadísticas (click para mostrar panel)
5. Puede gestionar usuarios completos (CRUD)

==========================================================================
ENDPOINTS DE LA API
==========================================================================

AUTENTICACIÓN:
- POST /api/users/register - Registro de usuarios
- POST /api/users/login - Autenticación
- GET /api/users/verify-token - Verificar token válido

TIENDAS (Requieren autenticación):
- GET /api/stores - Listar tiendas (paginado)
- GET /api/stores/{id} - Ver tienda específica
- POST /api/stores - Crear tienda (solo admin)
- PUT /api/stores/{id} - Editar tienda (solo admin)
- DELETE /api/stores/{id} - Eliminar tienda (solo admin)
- GET /api/stores/stats - Estadísticas (solo admin)

USUARIOS (Solo admin):
- GET /api/users/ - Listar todos los usuarios
- PUT /api/users/{id}/role - Cambiar rol de usuario
- PUT /api/users/{id}/toggle-status - Activar/desactivar usuario
